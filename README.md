# SGA Point of Sale Releases

This public repository contains approved desktop release packages and update metadata for the Sterling Gymnastics Academy Point of Sale application.

It intentionally contains no application source code, server code, database information, or credentials.

The SGA Point of Sale launcher downloads the latest release over HTTPS and verifies both the package size and SHA-256 checksum before installing it. If the update service is unavailable, the launcher opens the last locally verified version.
